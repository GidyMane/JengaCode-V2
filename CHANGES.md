## The events strip: the actual bug
The poster `<img>` tags carry `width="793" height="1983"` attributes. Those map
to a presentational height in the UA stylesheet, and because no CSS `height`
was set, the browser used **1983px** and ignored `aspect-ratio` completely.
Each poster was rendering nearly 2000px tall.

`height:auto` hands control back to `aspect-ratio`. Posters are now 2/3 with
`object-position:top center`, so the logo, headline and dates show rather than
a slice of the middle.

| | before | after |
| --- | --- | --- |
| poster image height | 1990px | 333px |
| events section, desktop | 2353px | 1289px |
| events section, mobile | 3480px | 1752px |

## Horizontal overflow bug
`.hero::before` (the decorative glow) sat 180px outside the layout, so the
document scrolled sideways at every width from 768px to 1440px. Contained with
`overflow-x:clip` on html and body. `clip` rather than `hidden` deliberately:
`hidden` makes the root a scroll container and breaks the sticky header.
Verified: `scrollWidth === viewport` at all 13 widths tested.

## Responsive
Added a breakpoint ladder at 1180, 1080, 900, 700, 560 and 380px. Also:

- gallery stays 2 columns on phones instead of 1, which alone cut 2500px
- service cards go 4 across, then 2, then 1
- program cards go 4 across instead of 3, removing a ragged trailing row
- hero badge becomes static below 700px instead of overlapping the photo
- posters lead the events grid below 900px
- meta, tracks, countdown and CTA all go full width on phones

Page height, desktop: 12,935px to 11,154px. Mobile: 20,367px to 16,132px.
